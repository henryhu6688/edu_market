
### 基于 EduMarket 的自研 Agent 对话引擎

通过自研 Agent 对话引擎实现智能客服与售后咨询，并解决了买家售前资料了解与卖家推广之间的沟通鸿沟——买家通过自然语言对话即可搜索资料、查阅文档、了解评价、完成下单，卖家无需逐一回复咨询。

**个人工作：**

- **Agent 编排引擎**：自研多轮 Tool Calling 循环框架，实现 LLM token 预测与确定性 IT 工作流的融合编排——每轮由 LLM 自主决策工具调用，引擎执行工具并收集结构化返回，按模式（导购/答疑/售后）动态切换可用工具白名单与行为策略，支持前处理（意图分类、购买状态校验）与后处理（输出格式校验、引用标注）
- **Prompt 工程体系**：针对导购、答疑、售后三种场景行为策略差异大的问题，将 System Prompt 按职责拆为角色定义、模式策略、行为规则、输出格式四个静态模块与任务状态层、用户画像层两个动态模块。静态模块支持外部 JSON 模板注入可脱离代码热更新，动态模块由引擎运行时从会话状态和长期记忆中实时生成，区块级可编辑标记控制 eval 优化粒度，模式切换仅替换策略模块其余保持不变，确保每轮对话都是在当前状态下实时编排的最优 Prompt
- **操作分级调度**：确定性操作（意图分类、购买校验）走 Workflow 直接执行不经过 LLM；多步决策任务进入 Agent 循环由 LLM 自主规划，降低不必要调用与 token 消耗
- **多层故障防护**：针对死循环、误调用、执行异常、事实编造等典型故障，实现 L1 精确重复熔断、L2 语义回路检测、L3 硬上限加工具配额，结合参数校验与结构化错误码逐层兜底
- **四层记忆机制**：针对长对话信息丢失、进度断裂、偏好遗忘的问题，设计四层记忆机制：短期记忆过滤无效消息，会话状态追踪事实与假设，长期记忆跨会话复用，外部知识按需检索
- **离线评估体系**：针对 Agent 行为无法用单元测试覆盖的问题，规则检查 + LLM 评分 + 人工抽检三层管道，覆盖正常流程、工具故障、越权、多轮干扰等情景

**项目难点：**

- **多模式 Prompt 编排复杂性**：针对三种业务模式 Prompt 策略差异大、切换需整体替换导致维护成本高的问题，将 Prompt 按职责模块化拆解——静态模块 JSON 模板注入 可脱离代码热更新，动态模块引擎运行时实时生成组合，模式切换仅替换策略模块其余不变，区块级可编辑标记控制 eval 优化粒度
- **多步推理死循环**：针对Agent多步推理出现死循环的问题，设计三层防护——L1 精确重复熔断、L2 Jaccard 语义回路检测、L3 工具独立配额设置硬上限
- **长对话上下文污染**：针对早期中间数据过时仍影响推理的问题，设计会话状态分层管理——事实层存 Tool 返回数据，假设层存推断，废弃层存被覆盖的旧信息，同源新数据自动淘汰


### 基于 EduMarket 的 RAG 智能文档问答

面向在线学习场景的 RAG 文档问答系统，离线侧实现 PDF/DOCX/PPTX 多格式解析、清洗、结构感知切片与向量化入库，在线侧实现混合检索、Cross-Encoder 精排与带来源引用的答案生成。

**个人工作：**

- **多格式文档解析与清洗管线**：针对 PDF/DOCX/PPTX 解析复杂度高、不可读文档污染索引的问题，自动解析 + 可读性检测 + OCR 降级兜底，不可读拒绝入库
- **结构感知切分策略**：针对固定窗口切分跨章节语义混杂的问题，按标题层级解析章节树后在边界切分，300-800 字弹性区间，切片附带章节路径作为来源标注
- **向量+BM25 混合检索**：针对纯向量检索语义相近但内容不对的误召回问题，Embedding 相似度与 BM25 关键词并行打分，RRF 融合排序，VectorStore 接口抽象支持 MySQL 降级
- **Cross-Encoder Rerank 精排**：针对 Embedding 召回排序精度不足的问题，粗召回 Top 20 经 Cross-Encoder 逐对重排取 Top 5，从宽泛候选集精确聚焦
- **两级缓存策略**：针对 Embedding 与 Rerank 外部 API 延迟和成本双高的问题，L1 精确缓存 + L2 语义缓存，API 调用量降低约 50%，端到端延迟降至毫秒级
- **多层面控制幻觉**：针对 LLM 检索不到内容时自行编造答案的问题，检索结果标注可信度分级，Prompt 约束仅基于检索内容回答，输出后正则校验自动修正，附带原文引用供验证

**项目难点：**

- **专业术语召回不足**：针对纯 Embedding 对技术术语语义泛化过强的问题，引入 BM25 关键词检索与向量检索混合，RRF 融合后经 Cross-Encoder Rerank 逐对精排，关键词命中优先提权
- **Chunk 切分跨段落引用丢失**：针对固定窗口切分后上下文断裂的问题，按Markdown标题层级解析章节树后在边界切分，切片附带章节路径，检索时自动拼回章节上下文
- **LLM 输出事实编造**：针对检索为空时 LLM 自行编造答案的问题，Prompt 注入可信度分级与 Source 状态，约束仅基于检索内容回答并标注原文引用，输出后正则校验自动修正
- **外部 API 调用成本与延迟双高**：针对RAG系统调用外部 API 延迟和成本双高的问题，通过Prompt压缩（去除冗余检索结果）+语义缓存（相似问题命中缓存直接返回）+短文本走小模型分流，API 调用量降低过半，端到端延迟从秒级压至毫秒级
